Suggestion Form

A PHP and MySQL tool for submitting, viewing, and updating ideas for university website and workflow improvements.

  • PHP
  • MySQL
  • JavaScript
  • HTML/CSS

Project overview

I built an internal suggestion workflow for the Texas A&M University–San Antonio Web Development Team. Staff can submit ideas for website features and workflow improvements in one place and return to them for review.

Each suggestion has a title, description, author, status, and creation and update dates. I worked on the submission and editing handlers, database reads and writes, and the list interface used to review the records.

How the suggestion workflow works

How the form validates requests

  • Required fields and length limits

    PHP requires a title of up to 100 characters and a description of up to 250. The handler rejects invalid values before updating the record.

  • Edit requests and status values

    The edit handler requires an authenticated session, a POST request, a valid suggestion ID, and a matching CSRF token. It accepts Submitted, In Progress, and Completed as status values.

Checking that edits persisted

I tested the editing and validation paths, corrected PHP rendering and grouping errors, and added a database read-back after the prepared UPDATE. The development notes confirm successful title and description edits.

During testing, a status edit redirected back to the list while the live database still showed the previous status. I investigated the deployed handler and database values. Status persistence and the final production rollout remained unverified in the development notes.
