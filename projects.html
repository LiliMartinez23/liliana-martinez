Case study / Web Services

Suggestion Form Generator

The problem

University suggestions need a place to be collected, reviewed, and managed after submission.

My contribution

I worked on the relational schema, input validation, and submission workflow. Records connect suggestions with users and review statuses, with generated IDs and timestamps. Create, read, update, and delete operations support ongoing record management.

From submission to review

  1. CollectA PHP form validates submitted information.
  2. StoreMySQL keeps the record and its user association.
  3. ReviewStaff view and manage suggestions and their statuses.
  • PHP
  • MySQL
  • HTML
  • CSS

Case study / Data automation

Weather Data Pipeline

The problem

Recurring weather-data files need to be imported into MySQL, with a record of what was processed.

My contribution

I built staged imports, processing logs, and input-file archiving, then scheduled recurring runs with cron. I also diagnosed database connectivity, permission, file-loading, and duplicate-record issues.

From file to database

  1. StageA Bash script loads incoming data into a staging table.
  2. ProcessMove records to the destination and log the activity.
  3. ArchiveKeep the processed input file for later reference.
  • Bash
  • MySQL
  • SQL
  • Linux / WSL
  • cron

Case study / Relational database design

Voter Data Integrity & Audit System

The problem

Voting records need consistent validation rules and a history of changes that can be reviewed.

My contribution

I designed relational tables with primary and foreign keys, check constraints, and validation rules. I created MySQL triggers to enforce voting rules and record changes for auditing and troubleshooting.

From record to audit trail

  1. ValidateConstraints check incoming records.
  2. EnforceTriggers apply the voting-data rules.
  3. RecordCapture changes in an audit record for review.
  • SQL
  • MySQL
  • Constraints
  • Triggers
